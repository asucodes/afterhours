# Third-party assets and design references

## Pixel Agents

Furniture, floor textures, and character sprite sheets in `public/assets/pixel-agents/` are reused from [Pixel Agents](https://github.com/pixel-agents-hq/pixel-agents), copyright (c) 2026 Pablo De Lucca, under its MIT license. The full license is retained at `public/assets/pixel-agents/LICENSE`.

Pixel Agents credits the character work to [JIK-A-4's MetroCity Free Top Down Character Pack](https://jik-a-4.itch.io/metrocity-free-topdown-character-pack). The original pack is published under CC0, permits commercial use, and welcomes attribution. We retain that credit here.

The AfterHours office layout, renderer, pathfinding, room boards, application shell, workflow engine, and provider integration are project-specific implementations. The reference project's camera controls, inspectable workers, directional movement, and spatial work states informed the revised interaction design.

## Other design references

- [Star Office UI](https://github.com/ringhyacinth/Star-Office-UI): room density and state-driven spatial activity. No artwork or source code from this project is included; its art has separate non-commercial restrictions.
- [AI Town](https://github.com/a16z-infra/ai-town): explorable world and inspectable characters. No source code or assets are included.
- [Paperclip](https://github.com/paperclipai/paperclip): operational navigation, clear state hierarchy, and contextual agent inspection. No source code or assets are included.

The earlier `swarm-animation` reveal was not integrated into the RPG workspace. It was a research reference for the initial direction.
